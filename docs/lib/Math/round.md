# Math.round

```ant signature
func Math.round(x: float64): float64
```

Math.round returns x rounded to the nearest whole number, with halves rounded away from zero.

<!-- end generated -->

## Basic examples

```ant
Math.round(2.5)  // 3.0
Math.round(-2.5) // -3.0
```
