# Time.Instant

```ant signature
type Time.Instant
```

Time.Instant is a moment on the time line, counted in nanoseconds since the Unix epoch, with no zone
and no calendar. It renders as 2026-10-22T14:03:05.5Z and spans 100 million days each way from the
epoch.
